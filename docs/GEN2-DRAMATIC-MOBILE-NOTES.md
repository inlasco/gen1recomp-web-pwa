# Third-party source strategy

Executable base: `randyadr/Gen2-3D-Sprites` tag `v0.2.81`, selected because it is the most recent public Gen2 integration found with current `render.compose` support, mobile canvas handling, touch camera and live Gen2 battle-world support.

Cross-checked against:

- `DramaticShape/DramaticShapeVoxelMod`;
- `UNDERdecoded/Gen2Recomped-DramaticShapes`;
- `absol89/DramaticShapeVoxelMod` (BattleArt fork, Gen1-oriented; concepts only, no BattleArt sprite pack copied);
- `inlasco/gen1recomp-web-pwa` Web/iPhone Dramatic Shape validation history.

Original licences and upstream documentation remain in the packaged source tree. The adaptation adds a source record and does not claim authorship of upstream work.
