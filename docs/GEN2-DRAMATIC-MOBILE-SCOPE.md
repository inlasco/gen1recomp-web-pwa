# Scope

Candidate only. No deployment and no merge to production.

Default enabled: Gen2 voxel world, touch/mobile camera, live 3D battle world, smart battle camera.

Default disabled: Stadium replacement sprites/models, alternate custom UI, player 3D model, Wilds visible-spawn feature, party follower, open-world expansion, heavy weather/clouds.

Gold/Silver are upstream-tested Gen2 targets. Crystal is routed through the same Gen2 gate and is an inlasComp target, but requires physical/runtime validation on the current Crystal engine before production acceptance.
